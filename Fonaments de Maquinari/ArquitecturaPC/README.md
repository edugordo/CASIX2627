# 🔧 Evidència 1 — Muntatge i neteja del PC

## 1. 🏷️ Identificació de l'ordinador

Agafa un dels ordinadors del taller dels gruixuts i etiqueta'l amb el teu nom demanant l'etiquetadora al professor.

## 2. 🔍 Comprovació dels components

Comprova que l'ordinador tingui tots els components necessaris i demana al professor els que faltin per deixar l'ordinador complet i a punt.

## 3. 🧹 Desmuntatge i neteja

Desmunta els components del PC i realitza una neteja dels diferents elements.

## 4. 🔩 Muntatge

Torna a muntar el PC correctament i comprova que funcioni.

## 📸 Evidències

Fes fotografies durant tot el procés:

- 📷 Ordinador abans de començar.
- 📷 Ordinador etiquetat.
- 📷 Components abans del desmuntatge.
- 📷 Procés de desmuntatge.
- 📷 Procés de neteja.
- 📷 Procés de muntatge.
- 📷 Ordinador una vegada muntat.
- 📷 Ordinador funcionant.
